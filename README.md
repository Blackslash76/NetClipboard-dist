<h1 align="center">NetClipboard</h1>

Clipboard condivisa **peer-to-peer sulla LAN** per Windows, con cronologia
unificata tra tutti i tuoi device, drag &amp; drop oltre il bordo, attraversamento
schermo (KVM software) e teletrasporto di finestre. Nessun server, tutto cifrato
punto-a-punto.

Questo è il **canale di distribuzione**: qui trovi il sito, l'installer e i
binari per l'aggiornamento automatico. Il codice sorgente non è pubblicato.
